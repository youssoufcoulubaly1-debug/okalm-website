📱 Instructions d'installation (Android)

  1. Téléchargez le fichier APK depuis le bouton ci-dessus.
  2. Ouvrez les Paramètres de votre téléphone → Sécurité.
  3. Activez « Sources inconnues » ou « Installer des applications inconnues ».
  4. Ouvrez le fichier APK téléchargé et appuyez sur Installer.
  5. Une fois installé, désactivez les « Sources inconnues » si vous le souhaitez.
  6. Lancez l'application et créez votre compte.
